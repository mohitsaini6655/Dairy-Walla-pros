# DairyWalla: Frequently Asked Questions (FAQ)

## 1. DairyWalla Kya Hai?
DairyWalla ek platform hai jo Dairy aur Ice-Cream Distributors aur unke Shopkeepers ke beech aane wali ordering aur communication problems ko solve karta hai. Is app ke through, distributors WhatsApp/calls ki jagah ek centralized dashboard par order receive karte hain, aur shopkeepers easily apna order place kar sakte hain.

## 2. Distributor App Ka Use Kaise Karein?
1. App download karein aur 'Distributor' profile create karein.
2. Apna business name aur location dalein. Aapko ek unique "Connection Code" milega.
3. Yeh Connection Code apne shopkeepers ke sath share karein jisse wo aapse connect ho sakein.
4. Apni order window (Order cut-off time) set karein.

## 3. Shopkeeper App Ka Use Kaise Karein?
1. App download karein aur 'Shopkeeper' profile banayein.
2. Apne distributor ka diya hua "Connection Code" enter karein.
3. Ek baar distributor request accept kar le, uske baad aap sidha app se daily milk/curd/ice-cream ka order place kar sakte hain!

## 4. Kya Shopkeeper kisi dusre distributor se connect ho sakta hai?
Nahi. Ek baar ek shopkeeper ek distributor se connect ho gaya, wo sirf usi distributor ke liye apna order place kar sakta hai jab tak distributor unhe platform se hata na de. Yeh "Close Loop Ecosystem" ensure karta hai ki koi bhi data leak na ho.

## 5. Kya mujhe app use karne ke liye paise dene honge?
App ka basic version download karne aur orders receive karne ke liye free hai. Advanced features (like Analytics, Custom Catalog) ke liye premium plans available hain. Shopkeepers ke liye app hamesha 100% free rahegi.
