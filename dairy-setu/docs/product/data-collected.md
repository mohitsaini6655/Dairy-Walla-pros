# Data Collected by DairyWalla

For legal compliance and app store transparency, here is the exact list of data points DairyWalla collects from its users.

## 1. Personal & Contact Information
- **Phone Number:** Used as the primary identifier and for authentication (OTP).
- **Email Address:** (Optional) Used for backup login and communication.
- **Name:** User's full name.

## 2. Business Information
- **Business Name / Shop Name:** To identify the entity placing or receiving orders.
- **GST Number:** (Optional) For B2B compliance.
- **Business Type:** Dairy, Ice Cream, or Dual.

## 3. Location Data
- **GPS Coordinates (Lat/Long):** Collected ONLY during profile setup or when explicitly adding a shop location, to help distributors plan delivery routes. Background location tracking is **NOT** used.
- **City / Delivery Area:** Text-based area codes for grouping.

## 4. Usage & App Data
- **Device Tokens (FCM):** Collected securely to send Push Notifications.
- **Crash Logs:** Anonymous technical data collected if the app crashes, used solely for debugging.
- **Order History:** Quantities of milk/curd/ice-cream ordered and timestamped, stored securely to generate analytics for the distributor.

*We do not access users' contacts, SMS inbox, camera, or photo gallery without explicit, feature-specific permission.*
