# DairyWalla Feature List

## Distributor App Features
- **Profile Management:** Set Business Name, Type (Dairy/Ice Cream), and specific Delivery Areas.
- **Connection Code:** Unique 8-digit code generated to securely onboard shopkeepers.
- **Order Cut-Off Timer:** Set a strict time (e.g., 9:00 PM) after which no orders are accepted for the next day.
- **Centralized Dashboard:** View aggregated total quantities of products ordered.
- **Order Management:** Accept, Reject, or Mark orders as 'Fulfilled'.
- **Shopkeeper Management:** View connected shopkeepers and remove inactive ones.
- **Push Notifications:** Instant alerts when an order is placed or a new shopkeeper requests a connection.
- **(Upcoming) Catalog Management:** Create custom product lists and prices.
- **(Upcoming) Analytics:** View sales trends over time.

## Shopkeeper App Features
- **Simple Onboarding:** Connect to a distributor securely using their Connection Code.
- **One-Click Ordering:** Simple '+' and '-' buttons to adjust quantities of daily items.
- **Order Status Tracking:** See if the distributor has Accepted, Rejected, or Fulfilled the order.
- **History:** View past orders to replicate or verify quantities.
- **(Upcoming) Payments:** Track dues and mark payments sent to the distributor.

## Admin Dashboard Features
- **Real-Time Metrics:** Total users, connections, active orders, and revenue estimation.
- **User Management:** View detailed lists of Distributors and Shopkeepers.
- **Blog Management:** Post and edit public blogs/updates visible on the main website.
- **System Health:** Live monitoring of API, connections, and database status.
