# Distributor Onboarding Checklist

Use this checklist when signing up a new distributor to ensure they successfully adopt the platform.

### Phase 1: Account Setup
- [ ] Download App from Play Store.
- [ ] Sign up using Phone/Email and select 'Distributor'.
- [ ] Fill in Business Profile (Business Name, Location).
- [ ] Note down the unique 8-digit **Connection Code**.
- [ ] Set Business Line (Dairy / Ice Cream / Dual).
- [ ] Set **Order Cut-Off Time**.

### Phase 2: First Connections
- [ ] Send WhatsApp Template #2 to their top 5 most tech-savvy shopkeepers.
- [ ] Call those 5 shopkeepers to ensure they downloaded the app.
- [ ] Ensure Distributor opens the app and "Accepts" the pending connection requests.

### Phase 3: First Order Run
- [ ] Ask the 5 shopkeepers to place their first dummy/real order via the app.
- [ ] Show Distributor how the orders populate on the dashboard.
- [ ] Show Distributor how to mark orders as "Completed" after dispatch.

### Phase 4: Full Rollout (Day 3-7)
- [ ] Distributor sends connection code to the rest of the shopkeepers.
- [ ] Refuse WhatsApp orders from the top 5 trained shopkeepers to enforce discipline.
- [ ] Check back with the distributor on Day 7 for feedback.
